# 🌐 Система Качественного Перевода с Сохранением Форматирования

Профессиональная система перевода документов на основе **MQM Framework** и **LQA методологии** с полным сохранением структуры, форматирования и таблиц.

## ✨ Ключевые особенности

- ✅ **6-этапная проверка качества** (MQM + LQA)
- ✅ **Полное сохранение форматирования** (шрифты, размеры, цвета, стили)
- ✅ **Перевод таблиц** с сохранением структуры
- ✅ **Два режима**: точный и художественный
- ✅ **Работа через Kiro** - без API ключа!
- ✅ **Оценка качества** по 4 MQM категориям

## 🚀 Быстрый старт

### Перевод документа:

```bash
# 1. Подготовка документа
python3 translate_with_kiro.py document.docx -s English -t Russian

# 2. Я перевожу все части (просто скажи "переведи")

# 3. Сборка с сохранением структуры
python3 translate_with_structure.py document
```

## 🎯 Процесс перевода (6 этапов)

1. **🔄 Начальный перевод** - базовый перевод (точный/художественный)
2. **✍️ Орфография** - проверка и исправление ошибок
3. **🗣️ Естественность** - проверка на естественность языка
4. **🔍 Точность смысла** - сравнение с оригиналом
5. **🎭 Эмоциональный тон** - проверка тона
6. **✨ Финализация** - финальная полировка

## 🔧 Технические детали

### Сохранение форматирования:
- Шрифты (название, размер, цвет)
- Стили (жирный, курсив, подчеркивание)
- Выравнивание (по левому краю, центр, по правому краю)
- Отступы и интервалы
- Таблицы (структура, границы, ширина колонок)
- Нумерация и маркеры

### MQM оценка качества:
- **Accuracy** (Точность) - совпадение смысла
- **Fluency** (Беглость) - естественность языка
- **Spelling** (Орфография) - грамматика
- **Tone** (Тон) - эмоциональная окраска

## 📖 Научная база
