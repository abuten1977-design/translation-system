# 📊 Архитектура системы перевода

## Процесс перевода (6 этапов)

```
┌─────────────────────────────────────────────────────────────┐
│                    ВХОДНОЙ ДОКУМЕНТ (.docx)                  │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Pass 1: Начальный перевод                                   │
│  • Художественный режим: естественность + тон                │
│  • Точный режим: точность + терминология                     │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Pass 2: Орфография и грамматика                             │
│  • Проверка орфографических ошибок                           │
│  • Проверка грамматики                                       │
│  • Автоматическое исправление                                │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Pass 3: Естественность (Fluency)                            │
│  • Проверка на естественность для носителей                  │
│  • Улучшение неестественных конструкций                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Pass 4: Точность смысла (Accuracy)                          │
│  • Сравнение оригинала и перевода                            │
│  • Проверка совпадения смысла                                │
│  • Исправление расхождений                                   │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Pass 5: Эмоциональный тон (Tone)                            │
│  • Сравнение тона оригинала и перевода                       │
│  • Проверка совпадения эмоциональной окраски                 │
│  • Корректировка тона                                        │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Pass 6: Финализация                                         │
│  • Финальная полировка                                       │
│  • Проверка целостности                                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│              ВЫХОДНОЙ ДОКУМЕНТ (.docx)                       │
│  • Переведенный текст                                        │
│  • Отчет о качестве (MQM оценки)                             │
└─────────────────────────────────────────────────────────────┘
```

## MQM Framework (Multidimensional Quality Metrics)

Система оценивает качество по 4 категориям:

| Категория | Описание | Проверка |
|-----------|----------|----------|
| **Accuracy** | Точность передачи смысла | Pass 4 |
| **Fluency** | Естественность языка | Pass 3 |
| **Spelling** | Орфография и грамматика | Pass 2 |
| **Tone** | Эмоциональный тон | Pass 5 |

## Научная база

1. **MQM Framework** (EU QTLaunchPad project)
   - Открытая система метрик качества перевода
   - Используется в профессиональной индустрии

2. **LQA (Linguistic Quality Assurance)**
   - Многоэтапная проверка качества
   - Стандарт ISO 17100

3. **Multi-Agent Translation Systems**
   - Специализированные агенты для разных аспектов
   - Итеративное улучшение качества

## Режимы перевода

### Точный (Precise)
- Максимальная точность передачи смысла
- Правильная терминология
- Подходит для: документация, юридические тексты, технические материалы

### Художественный (Literary)
- Естественность и красота языка
- Передача эмоционального тона
- Подходит для: маркетинг, креативные тексты, художественная литература
