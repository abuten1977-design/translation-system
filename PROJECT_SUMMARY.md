## 🎯 Ключевые особенности

### Научная база:
- ✅ **MQM Framework** - профессиональная система оценки качества
- ✅ **LQA методология** - многоэтапная проверка
- ✅ **ISO 17100** - международный стандарт
- ✅ **Multi-agent approach** - специализированные проверки

### Функциональность:
- ✅ Два режима: точный и художественный
- ✅ 6 этапов проверки качества
- ✅ Оценка по 4 MQM категориям
- ✅ Работа с .docx файлами
- ✅ Подробные отчеты о качестве

## 🚀 Как использовать

### 1. Установи зависимости:
```bash
pip install python-docx anthropic
```

### 2. Установи API ключ:
```bash
export ANTHROPIC_API_KEY="твой-ключ"
```

### 3. Запусти перевод:
```bash
python3 translate.py call_for_proposals.docx output_ru.docx \
  --source English --target Russian --mode precise
```

## 📊 Процесс перевода

```
Исходный текст
    ↓
Pass 1: Начальный перевод (режим: точный/художественный)
    ↓
Pass 2: Орфография и грамматика ✍️
    ↓
Pass 3: Естественность 🗣️
    ↓
Pass 4: Точность смысла 🔍
    ↓
Pass 5: Эмоциональный тон 🎭
    ↓
Pass 6: Финализация ✨
    ↓
Готовый перевод + Отчет о качестве
```

## 📈 Оценка качества (MQM)

Каждый перевод оценивается по 4 категориям:
- **Accuracy** (Точность) - совпадение смысла
- **Fluency** (Беглость) - естественность языка
- **Spelling** (Орфография) - грамматика и орфография
- **Tone** (Тон) - эмоциональная окраска
